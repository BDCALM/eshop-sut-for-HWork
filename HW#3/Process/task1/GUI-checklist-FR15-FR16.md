# GUI Checklist ban đầu - FR-15 và FR-16

## Phạm vi và giả định

- Phạm vi: phân hệ Web Admin, màn hình `Quản lý Sản phẩm` và chức năng `Import sản phẩm từ CSV`.
- Đối chiếu: README.md, giao diện `frontend-admin/src/App.jsx`, và checklist GUI trong `gui-usability-testing-skills/references/gui-checklist.md`.
- Môi trường mặc định để thực thi: Chrome stable, desktop 1280x800, truy cập Web Admin qua port 5174 trong GitHub Codespaces; backend sẵn sàng và tài khoản admin hợp lệ.
- `Not run` có nghĩa là chưa thực thi, không phải kết quả Fail. Khi thực thi, thay bằng `Pass`, `Fail` hoặc `Blocked` và thêm bằng chứng/ảnh chụp vào Ghi chú.
