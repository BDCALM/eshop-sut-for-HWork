### Ordered boundaries identified

#### 1. Search text length

The only evidence-backed lower boundary is the transition from an empty search
to a non-empty search:

- LB: `0` characters.
- Alpha: `1` character.
- Executable points: `0` and `1`.
- `LB - alpha` is `-1` character and cannot be entered.
- UB: unresolved; no maximum search length is specified or observed.

#### 2. Search result cardinality

The observable result classes are:

- `0` results: empty-result behavior.
- `1` result: one matching product.
- `2+` results: multiple matching products.

This is an output cardinality boundary, not a numeric input field. No maximum
result count or pagination upper boundary is specified, so no arbitrary UB is
created.
