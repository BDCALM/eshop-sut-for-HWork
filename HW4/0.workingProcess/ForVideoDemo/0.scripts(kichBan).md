Kịch bản quay video demo (tối thiểu 5 phút) cần bám sát quy trình 4 bước trong `SKILLS.md` và thỏa mãn các yêu cầu bắt buộc của Task 2 trong file HW04. Dưới đây là cấu trúc kịch bản ngắn gọn, sử dụng FR-19 (Quản lý người dùng) hoặc FR-05 làm ví dụ trọng tâm vì dễ demo việc AI bắt được bug thực tế.

* **Phần 1: Xác thực tác giả & Khởi tạo (Khoảng 30 giây)**
* Bắt đầu video bằng việc bạn hãy mở Command Prompt (CMD) hoặc PowerShell trên Windows, gõ lệnh `whoami` và `hostname` (hoặc bật face-cam) để minh minh danh tính theo đúng yêu cầu.


* Mở trình soạn thảo (như Cursor hoặc VS Code) và giới thiệu file `SKILLS.md` đã được nạp làm system prompt.
* Giới thiệu tính năng sẽ demo (ví dụ: FR-19 từ Pool C).




* **Phần 2: Step 1 - Sinh Test Data (Khoảng 1 phút)**
* Nhập prompt đầu tiên yêu cầu AI: *"Hãy áp dụng SKILLS.md để automate FR-19"*.
* Quay cảnh AI tuân thủ luật, **chỉ** sinh ra 12 test cases và file dữ liệu `.json`/`.csv` (Data-driven) mà chưa vội viết code.


* Mở file data lên để chứng minh test data đã được tách biệt hoàn toàn khỏi code.




* **Phần 3: Step 2 - Sinh Script & Review (Khoảng 1.5 - 2 phút)**
* Ra lệnh cho AI chuyển sang bước 2: *"Data ổn rồi, hãy viết script Playwright"*.
* Khi AI sinh xong code, trỏ chuột vào script để highlight 3 assertion patterns khác nhau mà AI đã comment.


* **Thực hiện Human Review (Bắt buộc):** Chỉ ra một lỗi hoặc điểm thiếu sót của AI trong script vừa sinh. Ví dụ: AI dùng CSS selector quá mỏng manh (fragile selector) hoặc quên xử lý thao tác chờ (flaky wait) khi xóa user. Thao tác sửa trực tiếp lỗi đó hoặc yêu cầu AI sửa lại, và nói rõ lý do bạn phải can thiệp.




* **Phần 4: Thực thi đa trình duyệt (Multi-browser Execution) (Khoảng 1 phút)**
* Mở terminal và chạy lệnh thực thi Playwright suite cho tính năng này.
* Quay lại quá trình test chạy qua ít nhất 3 trình duyệt (ví dụ: Chromium, Firefox, WebKit).




* **Phần 5: Report & Bug Report (Khoảng 1 phút)**
* Mở Playwright HTML Report (hoặc Allure) sau khi chạy xong.
* Chỉ chuột vào tiêu đề hoặc metadata của report để chứng minh có dòng chữ *"Run by: 23120242"*.


* Nếu test case chỉ ra bug của hệ thống (ví dụ: Admin tự xóa chính mình ở FR-19), hiển thị file Bug Report mà AI đã gen ở Step 3 trong `SKILLS.md` để kết thúc quy trình.
