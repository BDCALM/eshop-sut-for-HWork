### Ordered domains and boundaries

The evidence-backed ordered domain is customer-user-list cardinality,
excluding the logged-in admin baseline:

- LB: `0` customer users.
- Alpha: `1` customer user.
- Observed multiple-customer-user class: `2+` customer users.
- UB: unresolved; no maximum list size or pagination limit is specified.
- `LB-alpha` would be `-1` user and is not executable.

Target user ID is represented as an integer primary-key value, but the
available evidence does not define a user-facing minimum, maximum, or
malformed-ID contract. No arbitrary numeric ID boundary is created.

Authentication/role and current-admin protection are categorical/security
states, not numeric boundaries. Their enforcement must be verified during
execution.
